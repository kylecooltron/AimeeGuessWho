Deploy steps:

Push to main — the Action will run and create a gh-pages branch automatically
Go to your repo → Settings → Pages → set source to the gh-pages branch
In Render: New Web Service → connect your repo → it'll pick up render.yaml → set FRONTEND_ORIGIN to https://your-github-username.github.io in the Render dashboard env vars UI
